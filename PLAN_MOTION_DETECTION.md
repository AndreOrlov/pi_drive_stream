# План реализации системы детекции движения

## Обзор

Реализация модульной системы детекции движения с двумя алгоритмами (Grid-based Mean и Grid-based RMS), работающими напрямую с оригинальным разрешением кадра без сжатия. Система включает оптимизацию производительности, двухскоростное обновление фона, мониторинг и калибровку. Первичное тестирование на macOS с веб-камерой.

## Архитектура

Модульная система с гибридным подходом (Protocol + ABC):
- **Protocol** для гибкого контракта
- **ABC** с общими утилитами
- Два алгоритма: **Grid-based Mean** и **Grid-based RMS**
- **Работа с оригинальным разрешением** - без сжатия кадра
- **Двухскоростное обновление фона** - адаптивная скорость обучения
- Асинхронная обработка через `asyncio.to_thread`
- Система мониторинга для калибровки

## Ключевой принцип работы

**Разбиение кадра на сетку без сжатия:**

1. Кадр: 640x480 пикселей
2. Сетка: 24x18 ячеек (задается в конфиге)
3. Размер ячейки: автоматически вычисляется
   - `cell_width = 640 / 24 = 26.67 пикселей`
   - `cell_height = 480 / 18 = 26.67 пикселей`
4. **Фон хранится компактно:** матрица 18x24 (одно значение на ячейку)
5. **Детекция:** для каждой ячейки анализируем все пиксели

## Этап 2: Grid-based Mean детектор

**Файл:** `app/overlay/motion/grid_mean_detector.py`

### GridMeanDetector

**Алгоритм:**

```python
Для каждой ячейки [j][i]:
    1. Извлечь все пиксели ячейки из текущего кадра
       cell_pixels = frame[y1:y2, x1:x2]

    2. Вычислить среднюю яркость
       current_avg = cell_pixels.mean()

    3. Сравнить с фоном
       diff = abs(current_avg - background[j][i])

    4. Детекция
       motion[j][i] = 1 if diff > threshold else 0

    5. Обновление фона (двухскоростное)
       if motion[j][i] == 0:
           alpha = alpha_fast  # 0.1
       else:
           alpha = alpha_slow  # 0.01

       background[j][i] = alpha * current_avg + (1-alpha) * background[j][i]
```

**Параметры:**
- `base_alpha: float = 0.02` - базовая скорость обучения
- `alpha_fast_multiplier: float = 5.0` - множитель для быстрого обновления
- `alpha_slow_multiplier: float = 0.5` - множитель для медленного обновления
- `threshold: float = 25.0` - порог детекции
- `use_adaptive_threshold: bool = True` - адаптивный порог на основе std

### AsyncGridMeanDetector

Асинхронная обертка через `asyncio.to_thread()`

## Этап 3: Grid-based RMS детектор

**Файл:** `app/overlay/motion/grid_rms_detector.py`

### GridRMSDetector

**Алгоритм (более точный):**

```python
Для каждой ячейки [j][i]:
    1. Извлечь все пиксели ячейки
       cell_pixels = frame[y1:y2, x1:x2].astype(float)

    2. Вычислить среднюю яркость
       current_avg = cell_pixels.mean()

    3. Вычислить разности с фоном для каждого пикселя
       # Используем фон как базовую яркость ячейки
       diff = cell_pixels - background[j][i]

    4. RMS (Root Mean Square)
       rms = sqrt(mean(diff²))

    5. Детекция
       motion[j][i] = 1 if rms > threshold else 0

    6. Обновление фона (двухскоростное, как в Mean)
       background[j][i] = alpha * current_avg + (1-alpha) * background[j][i]
```

**Параметры:** те же + специфичные для RMS

**Преимущества RMS:**
- Более чувствителен к изменениям
- Квадратирование усиливает большие изменения
- Статистически обоснован

### AsyncGridRMSDetector

Асинхронная обертка

## Детали двухскоростного обновления фона

**Для каждой ячейки независимо:**

```python
# Вычисление скорости обновления
if motion[j][i] == 0:
    # НЕТ движения → БЫСТРО адаптируемся к новому освещению
    alpha = base_alpha * alpha_fast_multiplier  # 0.02 * 5 = 0.1
else:
    # ЕСТЬ движение → МЕДЛЕННО (не впитываем объект в фон)
    alpha = base_alpha * alpha_slow_multiplier  # 0.02 * 0.5 = 0.01

# Обновление фона этой ячейки
background[j][i] = alpha * current_avg + (1 - alpha) * background[j][i]
```

**Эффект:**
- При включении света: быстрая адаптация за 10 кадров
- Движущийся объект: не становится фоном
- Остановившийся объект: плавно впитывается в фон за 15-20 кадров

## Система мониторинга и калибровки

### Данные на экране

**Основная статистика:**
- Количество активных ячеек / всего
- Процент покрытия
- Алгоритм и размер сетки
- Размер ячейки в пикселях
- FPS детекции
- Время обработки
- Средняя яркость
- Текущий порог
- Режим обновления фона (2-speed)

### Процесс калибровки

**Шаг 1: Базовая калибровка**
- Статичная сцена → Motion < 1%
- Brightness 50-200

**Шаг 2: Тест движения**
- Движение → Motion 5-20%
- FPS стабильный

**Шаг 3: Тест изменения света**
- Auto-reset срабатывает
- Восстановление за 2-3 сек

**Шаг 4: Оптимизация**
- Detection time < 30ms

### Настройка параметров

**Проблема: Много ложных срабатываний**
→ Увеличить threshold: 25 → 35
→ Уменьшить base_alpha: 0.02 → 0.01

**Проблема: Не видит медленные движения**
→ Уменьшить threshold: 25 → 15
→ Увеличить сетку: 24x18 → 32x24

**Проблема: Низкая производительность**
→ Уменьшить сетку: 24x18 → 16x12
→ Переключить на grid_mean (быстрее чем grid_rms)
→ Увеличить skip_frames
